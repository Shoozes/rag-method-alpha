# Glossary

- **Collection**: the user-facing name for one imported corpus. The stable API
  field remains `companion_id` for compatibility.
- **Pocket**: a bounded source class such as global, vault, lore, or memories.
- **Unicode proof text**: café, naïve, Straße, and Σίσυφος remain valid UTF-8
  through strict normalization and scalar-safe indexing.
